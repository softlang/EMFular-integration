Details

When modifying a single element with several properties, a details view (usually as a modal) can be helpful. We offer a generic (element) details component that takes all attributes and all relationships of the metamodel into account. It uses a container details component to display the specific properties for each relationship.

The Element Details Component

We offer a functionality to re-organize the element within the tree-backbone by assigning a different parent element. There is also a dedicated section for all serializable attributes, and a final one for all references.
