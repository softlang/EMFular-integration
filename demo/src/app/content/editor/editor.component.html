Editor Components

We provide completely wired editors, as well as all the necessary primitives for building a more tailored editor of your own. Our general assumption is that an editor consists of three parts:

  • the modeling canvas
  • the editor bar, providing file-level functionality such as loading and saving models
  • the model-specific palette for creating new model elements

Modeling Canvas

You can use the normal canvas of EMFular-diagram to project your own components onto. However, you can also choose the tree-based canvas that has the tree-component already wired in.

Creation Palettes

We offer a simple abstraction for creation buttons:

It should be sufficient to define a button with a label, and an associated action, as well as an optional icon (via ist string name), and a disabled flag. We provide a palette, that consumes such button definitions to display creation buttons (or other buttons you specify).
